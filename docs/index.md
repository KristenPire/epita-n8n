# Automation with n8n 👋

Welcome. This module is **12 hours over 4 sessions**. You will learn to build automated
workflows and **AI agents** with [n8n](https://n8n.io).

At the end you build **your own project**, alone, and you present it.

!!! info "You always work alone"
    There are **no teams** in this module. Every session is individual work. You help each
    other, but each person has their own n8n instance and their own project.

## The 4 sessions

| Session | Time | What happens |
|---|---|---|
| **Séance 1 — Introduction and workflows** | 3 h | What automation is. The n8n interface, nodes, tools. You build 5 workflows, **no AI** yet. Guided exercises. |
| **Séance 2 — Agent-oriented workflows** | 3 h | How an AI agent works inside a workflow. You add AI steps, then a real **AI Agent node**. Guided exercises. |
| **Séance 3 — Project launch** | 2 h | You pick your own real use case and start building a production-quality agent workflow. |
| **2 weeks** | — | Autonomous work. You build your project alone. |
| **Séance 4 — Soutenance** | 3–4 h | You present your workflow, explain how it works, and justify why it is useful. This is the exam. |

## Evaluation

Your grade comes from **the project + the soutenance**. Two things are graded:

1. **How it works** — you can explain every step of your own workflow.
2. **Why it is relevant** — you can justify the use case and your design choices.

Details on the project brief and the soutenance guide arrive in Séance 3 and 4.

## 🚚 FoodFleet — the demo company

In Séance 1 and 2, every exercise uses the **same fake company: FoodFleet**.

FoodFleet is a small B2B startup. It delivers lunches to offices. It has normal problems:
watch competitor menus and prices, catch new leads from a web form, sort customer
feedback, build the daily order list, send a weekly report.

You do **not** invent a use case in Séance 1 and 2. You work on FoodFleet, like a new
engineer joining the company. This keeps the focus on n8n itself.

From **Séance 3** you stop using FoodFleet. You choose your own project.

## 3 rules

!!! warning "Rule 1 — Nobody touches your keyboard"
    Someone helps you? They **point at the screen and explain**. YOU type. This is how you
    really learn it.

!!! warning "Rule 2 — Try 3 things first"
    Stuck? In order: **1)** re-read the step and open the next hint, **2)** ask your
    neighbour, **3)** search the error message. Then raise your hand.

!!! warning "Rule 3 — This cohort moves fast"
    You are engineering and AI students. The exercises below were written for a less
    technical audience, so the pace here is **faster**. We skip the long explanations about
    JSON and HTTP. If an explanation feels obvious, it is: skip it and go to the next
    checkpoint.

## How an exercise page works

Every exercise page has the same shape:

- A **Goal** line: what works at the end.
- **CP1, CP2, CP3…** = checkpoints. Small steps. Each one ends with
  ✅ **Done when**: a thing you can see on screen.
- **Hints** in closed boxes. Open them one by one, only when you are stuck. The last hint
  is usually the answer.
- Some exercises contain **one planted bug**. Finding it is part of the exercise.
